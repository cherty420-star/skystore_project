# SkyStore - Интернет-магазин цифровых товаров

## Описание проекта
SkyStore - это веб-приложение для продажи цифровых товаров: плагинов, примеров кода, телеграм-ботов и других IT-решений.

## Функциональность
- Главная страница с каталогом товаров
- Страница контактов с формой обратной связи
- Адаптивный дизайн на Bootstrap 5

## Технологии
- Python 3.10+
- Django 4.2+
- Bootstrap 5
- SQLite (для разработки)
